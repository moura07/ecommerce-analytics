# Camada Bronze — Dados Brutos

Esta camada contém os dados brutos do projeto, exatamente como foram disponibilizados pela fonte original, sem qualquer tipo de transformação.

## Fonte dos Dados

Dataset público da Olist (Kaggle):
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Conteúdo

- Arquivos CSV originais do dataset Olist
- Nenhuma limpeza ou modificação aplicada

## Versionamento

Os dados brutos **não são versionados** no repositório por boas práticas:
- Arquivos grandes
- Dados públicos facilmente recuperáveis
- Evita duplicação desnecessária no GitHub

A pasta `olist_raw/` é mantida apenas como estrutura, contendo um README e um `.gitkeep`.

## Responsabilidade da Camada

- Preservar os dados na forma original
- Servir como ponto inicial do pipeline
- Garantir rastreabilidade da fonte
