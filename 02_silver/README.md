# Camada Silver — Dados Tratados

A camada Silver é responsável pela limpeza, padronização e validação dos dados brutos.

Aqui ocorre a transformação dos dados para um formato consistente e confiável, pronto para análises mais avançadas.

## Atividades Realizadas

- Leitura segura de arquivos CSV
- Padronização de tipos de dados
- Conversão de datas
- Tratamento de valores nulos
- Verificação de duplicidades
- Validação de volume e consistência

## Conteúdo da Pasta

- `notebooks/`
  - Notebook de EDA e limpeza (`01_eda_limpeza.ipynb`)
- `olist_processed/`
  - Dados tratados gerados a partir do notebook

## Versionamento

- Notebooks `.ipynb` são versionados
- Dados tratados

- Aplicar regras de negócio básicas
